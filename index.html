Мета проєкту

Створення комп'ютерних ігор — це чудовий спосіб освоїти базові концепції програмування: об'єктно-орієнтований підхід, роботу з графічними інтерфейсами (GUI), обробку подій та алгоритми управління станом. Python є однією з найкращих мов для старту завдяки простому синтаксису.Мета проєктуДослідити можливості інтерактивної розробки на Python та створити спрощену версію класичної гри «Тетріс» за допомогою вбудованих графічних інструментів.

◆ Чому саме Python?

Python поєднує зрозумілий синтаксис із потужними принципами ООП. Це робить його ідеальним інструментом для швидкого створення та тестування ігрових алгоритмів.

◆ Головна мета

1. Вивчити особливості інтерпретатора Python. 2. Ознайомитися з бібліотекою tkinter для створення графіки. 3. Розробити алгоритм логіки гри «Тетріс» (рух фігур, перевірка ліній, підрахунок балів). 4. Реалізувати та протестувати код.

◆ Стек технологій

Інтерпретатор Python 3 та стандартне графічне середовище Tkinter (Canvas). Програма автономна і не потребує встановлення сторонніх бібліотек. Інтерпретатор Python може працювати у двох основних режимах: 1. Скриптовий (пакетний): Код пишеться у файл (наприклад, main.py) і запускається повністю. 2. Інтерактивний (REPL — Read-Eval-Print Loop): Код виконується рядок за рядком. Це ідеальний майданчик для тестування окремих функцій, математичних розрахунків або швидкої перевірки роботи графічних модулів. Для створення візуальної частини «Тетрісу» ми використовуємо Tkinter — стандартну бібліотеку для створення графічних інтерфейсів користувача. Вона дозволяє малювати об'єкти на «полотні» (Canvas) та прив'язувати функції до клавіш клавіатури.

       

Матрична модель поля

Матриця ігрового поля класичного Тетрісу має розмір 20 рядків на 10 стовпчиків. Кожна фігура (тетраміно) складається з 4-х блоків.На першому практичному етапі було спроєктовано «склянку» гри. Вся логіка руху базується на двовимірній матриці розміром 20 рядків на 10 стовпчиків.

Значення 0 означає, що клітинка абсолютно порожня. Якщо фігура падає на дно, клітинка записує в себе її колір.

Ключові ігрові алгоритми:

Collision Detection:Крок 1: Ініціалізація вікна та ігрового поля Спочатку створимо вікно, ігрове полотно та задамо базові константи (розмір клітинки, кольори фігур). Крок 2: Опис архітектури класу Tetris Щоб гра працювала коректно, об'єднаємо логіку в один клас. Його завдання — зберігати стан поля (де вже лежать зафіксовані блоки), керувати поточною фігурою та оновлювати екран. Крок 3: Логіка генерації та руху фігур Додамо всередину класу методи для створення нової фігури, перевірки зіткнень (валідації руху) та фіксації фігури на дні. Перевірка, чи не виходить фігура за межі поля і чи не врізається в інші блоки. Автоматичне падіння фігури вниз за таймером. Крок 4: Керування клавіатурою та очищення лінійКористувач повинен мати змогу рухати фігуру вліво/вправо та повертати її. Також додамо алгоритм видалення заповнених рядків. Видалення заповнених рядків та нарахування балів/ Крок 5: Отрисовка (Рендеринг) Функція draw очищує полотно і щоразу малює сітку заново на основі масиву self.grid та поточної фігури. Опис процесу роботи над грою (Покроковий аналіз)

1. Проектування структури: На першому етапі було обрано двовимірний масив (список списків) розміром 20 \times 10 як модель ігрового поля. Нуль означає порожнечу, а назва кольору — статичний блок. 2. Реалізація геометрії фігур: Кожна фігура описана через відносні координати чотирьох точок. Наприклад, паличка ("I") — це чотири блоки в один ряд. 3. Створення ігрового циклу: На відміну від звичайних консольних програм, де використовується нескінченний цикл while True (який би просто "завісив" графічне вікно), у tkinter застосовано асинхронний метод root.after(500, move_down). Він працює як таймер, що викликає падіння фігури кожні пів секунди. 4. Алгоритм зіткнень: Метод is_valid_move — це серце логіки. Перед кожним рухом (вниз, вліво чи поворот) програма прораховує "майбутні" координати фігури. Якщо хоч один блок виходить за рамки вікна або накладається на вже зайняту клітинку поля — дія скасовується. 5. Поворот фігур: Застосовано лінійну трансформацію на площині (матриця повороту навколо однієї з точок фігури як локального центра координат).
