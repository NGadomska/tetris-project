Мета проєкту:

Створення комп'ютерних ігор — це чудовий спосіб освоїти базові концепції програмування: об'єктно-орієнтований підхід, роботу з графічними інтерфейсами (GUI), обробку подій та алгоритми управління станом. Python є однією з найкращих мов для старту завдяки простому синтаксису.Мета проєктуДослідити можливості інтерактивної розробки на Python та створити спрощену версію класичної гри «Тетріс» за допомогою вбудованих графічних інструментів.

◆ Чому саме Python?

Python поєднує зрозумілий синтаксис із потужними принципами ООП. Це робить його ідеальним інструментом для швидкого створення та тестування ігрових алгоритмів.

                   
                   
                       

◆ Головна мета

                       

Дослідити принципи розробки 2D-ігор, запрограмувати поведінку випадкових фігур (тетраміно) та реалізувати систему відстеження ігрових подій у реальному часі.

                   
                   
                       

◆ Стек технологій

                       

Інтерпретатор Python 3 та стандартне графічне середовище Tkinter (Canvas). Програма автономна і не потребує встановлення сторонніх бібліотек.

                   
               
           
       
       
 

Завдання:

Завдання: 1. Вивчити особливості інтерпретатора Python. 2. Ознайомитися з бібліотекою tkinter для створення графіки. 3. Розробити алгоритм логіки гри «Тетріс» (рух фігур, перевірка ліній, підрахунок балів). 4. Реалізувати та протестувати код.

Значення 0 означає, що клітинка абсолютно порожня. Якщо фігура падає на дно, клітинка записує в себе її колір.

                   
                   
                       

Ключові ігрові алгоритми:

                       

Collision Detection: Перевірка зіткнень зі стінами та фігурами.

                       

Line Clearing: Автоматичне видалення заповнених ліній.

                       

Ігровий цикл: Автоматичне падіння фігур кожні 500 мс.
